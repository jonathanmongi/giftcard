# Interactive Gift Card

A small interactive gift-card experience built with vanilla HTML, CSS, and JavaScript. The page uses a click-to-reveal flow and visual feedback to turn a static card into a short browser interaction.

## Run locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000/gift.html> in a browser.

## Project structure

- `gift.html` contains the card content and interactive controls.
- `script.js` manages the reveal and follow-up interaction.
- `style.css` controls the card layout, colors, and animation.

## What it demonstrates

This project is a focused exercise in semantic page structure, DOM event handling, progressive content reveal, and CSS-driven presentation without a framework or build tool.
